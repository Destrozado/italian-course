# Phase 33 — UI Design Contract

> Visual and interaction contract for the three exercise/exam screens (multiple-choice, match, word-buttons). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Brownfield UI-only.** The engine (cascade D-54, `applyResultToSession`/`applyImmediateFailure`, sampler, slot-engine, grading `registry[type].grade`, localStorage, schema, migrations) MUST NOT be touched. This phase repaints the `<template x-if="currentScreen === 'session'">` block (index.html ~390-668) + adds CSS to `app.css`/`styles.css` + at most presentational getters/bindings. `x-text` is the exclusive data binding (anti-XSS invariant T-02-01) — never `x-html`. Button labels (Continuar / Siguiente / Comprobar) stay hardcoded.
>
> Consumes the Phase 32 Editoriale layer: the `--ed-*` tokens, self-hosted fonts in `vendor/fonts/` (Spectral / Hanken Grotesk / Space Grotesk), and `app.css` (now the reset/base layer — Pico was REMOVED in Phase 32 / GAP-01). **Do NOT redefine the palette — reuse the existing `--ed-*` tokens.** Do NOT re-introduce Pico.

## Typography

All sizes/weights below come from `design_handoff_italiano_redesign/README.md` §Tipografía (high fidelity). Three families only; weights are bounded per family as Phase 32 declared.

| Role | Family | Size | Weight | Line Height |
|------|--------|------|--------|-------------|

| Match prompt (if shown) | Spectral (serif) | 24px | 600 | 1.3 |
| Option / pill text | Spectral (serif) | 18px | 500 | 1.3 |
| Feedback box title ("¡Esatto!" / "Quasi…") | Spectral (serif) | 17px | 600 | 1.3 |
| Overline (category context) | Hanken Grotesk | 11px | 700 | 1.2 · letter-spacing 2–2.5px · UPPERCASE · color `--ed-faint-2` |
| Meta / feedback body / explanation | Hanken Grotesk | 13px | 400 | 1.5 · color `--ed-muted` |
| Match note ("N de M emparejadas") | Hanken Grotesk italic | 12px | 400 | 1.5 · color `--ed-faint` |
| Bottom CTA / secondary buttons | Hanken Grotesk | 16px | 700 | 1 |
| Progress counter `NN/NN` | Space Grotesk | 13px | 700 | 1 |
| Timer chip seconds | Space Grotesk | 13px | 700 | 1 |
| Word-buttons key superscript (`.kbd-hint`) | Hanken Grotesk | `0.65em` (relative, derived ≈10px) | 500 | 1 · color `--ed-faint` |

**Match-note size resolution (checker flag):** the match note was 12.5px, only 0.5px below the 13px meta/body size — too close to read as a distinct step. Resolved to **12px** (nearest 4-multiple, a clear step below 13). This stays within the handoff's stated subtitle band of "12.5–14" (§Tipografía), and the note is additionally distinguished by *italic* style and the lighter `--ed-faint` color. Update `.match-note` (or equivalent) to 12px italic.

Effective set per family: **serif 4 sizes (30/24/18/17)**, **sans 4 sizes (16/13/12/11)**, **mono 1 size (13)**. Weights used: serif 500/600, sans 400/700, mono 700 — within the Phase 32 declared ranges. Body line-height 1.5; serif/heading line-height 1.3 (prompt) / 1.2 (overline), per handoff.

## Component & Interaction Contract (exercise-specific)

> This section carries the locked CONTEXT.md decisions the executor must implement exactly. The 6-dimension checker reads Color/Typography/Spacing/Copywriting above; this block is the interaction source of truth.

### Top bar (EX-01) — applies to all three types

- Circular back button top-left, glyph `‹` → calls existing **`requestReturnToHome`** (keeps the confirmation). Label "Volver al home" (D-10).
- **Accessibility — back button accessible name:** the back button is icon-only (glyph `‹`), so it MUST carry `aria-label="Volver al home"` at the element level (static attribute, or Alpine `:aria-label`). This gives the control an accessible name independent of its visible glyph. (It calls the existing `requestReturnToHome`.)
- Green progress bar = % of set (reuse `sessionProgressLabel` / `sessionCursor` + `sessionExerciseIds.length`).
- Counter `NN/NN` in Space Grotesk (derive from existing progress state; presentational getter only).
- **Timer chip** (Space Grotesk, remaining seconds) shown WHEN `sessionTimed && sessionFeedback === null`, **AND keep the depleting `<progress>` bar** (`.session-timer-bar`) as reinforcement (D-11). Engine (`sessionTimed`, `sessionTimeRemainingMs`, `sessionTimeLimitMs`) is intact — presentation only.
- "Reiniciar ejercicios" stays at the BOTTOM as a secondary action (D-10, preserves UX-01), beside "← Volver al home", under the existing `<hr>`.

### Question block (EX-02)

- **Overline** = reuse `sessionContextLabel` (e.g. "Examen: Avere", "Repaso (20 ejercicios)"), repainted as Editoriale overline: UPPERCASE, Hanken 11, letter-spacing 2–2.5px, `--ed-faint-2` (D-06). No new derivation logic.
- **Prompt** = serif 30px, line-height 1.3, with the literal `___` gap rendered **visibly styled** (D-08).
- **OMIT** the handoff's italic "suggestion" line — no data source, do not add a JSON field (D-07).

### Gap rendering & fill (EX-02 / EX-03 / EX-05) — D-08

- Prompts contain a literal `___` (verified in JSON, e.g. `"Lui ___ ventidue anni."`). Split the prompt on `___` (presentational getter, no engine change) to render the gap as a styled inline slot.
- **Pre-grading:** gap shown empty/styled (NOT pre-filled — consistent with the 1-step flow; there is no pre-check selection state).
- **Post-grading:** fill the gap with the answer — **green + underline if correct**, **red + strikethrough if wrong**. Applies to multiple-choice AND word-buttons.

### Multiple-choice (EX-02 / EX-03) — 1-STEP, D-01 / D-02 / D-04

- **DELIBERATE deviation from EX-03 and the handoff 2-step flow.** Tapping an option grades INSTANTLY (`sessionSelectOption` → `grade` → `applyResultToSession`). There is **NO "Comprobar" button**, **NO pre-check `green-selection` state**, and **NO pre-fill of the gap before grading**. Keyboard 1-4 grades instantly (existing behavior preserved).
- 4 options stacked, gap 10px, serif 18, resting fill `--ed-surface`, border `--ed-border-soft` 1.5px, radius 14 (`--ed-radius-feedback`), padding 15×18, `justify-content: space-between` (text left, mark right).
- **After grading (the handoff *comprobado* states DO apply — D-02), map onto existing `.correcta`/`.incorrecta` classes repainted:**
  - Correct option (`perm === correctIndex`) → `green-tint` fill + green 2px border + `green-on-tint` text + `✓`.
  - Chosen-incorrect option (`perm === sessionSelectedIndex` on incorrect) → `red-tint` fill + red 2px border + `red-text` + `✗`.
  - All other options → `opacity: 0.5`.
- **Feedback box** (D-09): `margin-top` 16, radius 14, `green-tint`/`green-tint-border` on correct or `red-tint`/`red-tint-border` on wrong; **serif Italian title "¡Esatto!" (correct) / "Quasi…" (wrong)** followed by the existing pedagogical `payload.explanation` (reuse `.session-explanation` + the "¿Por qué?" reveal affordance on correct — both preserved).
- **Advance is manual always** (D-04): after grading, the user presses the bottom CTA. CTA label = **"Continuar →"** when feedback is present (correct or incorrect). No auto-advance in grammar modes; the 600ms auto-advance stays SONG-MODE ONLY (intact).

### Match (EX-04) — PER-PAIR, D-03 / D-05

- **DELIBERATE deviation from EX-04.** Keep the current per-pair flow: each pair validates instantly with a red flash + immediate D-61 cascade on first failure (`matchHadFailure`). There is **NO "match-all-then-Comprobar"** and **NO disabled CTA** (the EX-04 "CTA disabled until complete" sub-criterion is intentionally not met).
- Two columns of serif-17 pills (`.match-grid` / `.match-col` preserved). Resting pill: `--ed-surface` fill, `--ed-border-soft` border, radius 13.
- Apply only the handoff visual states **compatible with the per-pair flow (planner decides — D-05):**
  - **Desirable:** numeric badge per matched pair (green circle ~20px, white number, Hanken 12/800) + `green-tint` fill on matched pills (`green-tint-border`, `green-on-tint` text) — replaces the current `¹`/`ᵃ` suffixes + `.match-consumed`.
  - **Selected/active pill:** repaint `.match-selected` as green 2.5px border + `--ed-surface` + green shadow (`0 6px 16px rgba(47,125,86,.18)`).
  - **Candidate pill (other column):** dashed green 2px border + "?" — apply ONLY if it fits the current 2-column layout without forcing it (D-05).
  - **Failure flash:** repaint `.match-flash` red animation (≤300ms).
- Optional centered italic note "N de M emparejadas" derived from match state (presentational only). Typeset at 12px Hanken italic, `--ed-faint` (see Typography).

### Word-buttons (EX-05) — extrapolate Editoriale, D-12

- Not in the handoff. Extrapolate the language **consistent with multiple-choice:**
  - Word bank (`.wb-bank`) = pills on `--ed-surface`, border `--ed-border-soft`, radius `--ed-radius-ghost` (12); placed words dim/disabled (repaint `.wb-placed`).
  - Answer area (`.wb-answer`) with stable styled gap; post-grading fill per D-08 (green underline / red strikethrough).
  - Feedback green/red + serif Italian title (D-09), reusing `.session-explanation`.
  - Keep mechanics intact: `wordButtonsAddWord` / `wordButtonsRemoveWord` / `wordButtonsCheck`, `bankWithKeys`, key superscripts `¹..⁹` (`.kbd-hint`). Word-buttons keeps its existing **"Comprobar"** button (assemble-then-check is its native model) → then "Siguiente".

### Transitions

- Color/border/opacity transitions ~150–200ms ease (handoff §Interactions). Switch/match-flash ≤300ms. No complex animation.

### Focus / disabled (handoff-silent → declared here, prescriptive)

- **Focus-visible:** 2px green (`--ed-green`) outline with 2px offset on options, pills, bank/answer buttons, back button, and the bottom CTA (keyboard accessibility; do not rely on color alone — the `✓`/`✗` glyphs and underline/strikethrough carry meaning non-chromatically).
- **Disabled** (options/pills during feedback via `:disabled`): no extra dim beyond the post-grading `opacity: 0.5` rule; cursor `default`. Word-buttons "Comprobar" disabled uses the handoff `cta-disabled-bg` `#dcd7cb` / `cta-disabled-text` `#a89f8c`.
- **Hover** (desktop): subtle border darken toward `--ed-ink` on resting options/pills (~120ms); no fill change pre-grading.
