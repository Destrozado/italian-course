<objective>
Vertical slice de UI que entrega **home + picker + session migrada** end-to-end. Al final del plan, el autor abre `http://localhost:3000` y ve:
1. La home con tabla densa de categorías (al menos `avere` mostrada con su estado actual).
2. Botones `Repaso 20` / `Test completo` que abren un picker compartido.
3. Picker con checkboxes que arranca una sesión real.
4. Sesión que funciona exactamente como Phase 1 (multiple-choice render + feedback + auto-avance) pero ahora dentro del `appShell` unificado.
5. Al completar la sesión, el state se persiste con la nueva firma `applySessionResult(state, sessionResult, content, today)` Y la cascada/promociones aplican.

Sin resumen aún (eso es Plan 02-04). Sin Test completo persistente in-flight aún (eso es Plan 02-04). Pero el bucle Repaso end-to-end funciona y la persistencia v2 con cascada/promociones es observable inspeccionando localStorage tras cerrar una sesión.

Es el refactor más arquitectural del proyecto; hacerlo en un plan separado evita mezclar refactor + features nuevas.
