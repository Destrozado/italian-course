<specifics>
## Specific Ideas

- **Avere es la categoría más pequeña** (23 ejercicios). Plan 7.2-01 itera el patrón con bajo riesgo — si emerge ajuste tonal aquí, se aplica a las 4 categorías restantes sin desperdicio.
- **Essere se beneficia de tener Avere ya curado**: las distractoras tipo "1 avere + 2 essere mal + 1 correcta" (patrón D-91 de Phase 5) ahora pueden referenciar explicaciones de Avere para reforzar el contraste pedagógico.
- **Verbos-movimiento contiene multi-cat con Essere** (auxiliar passato prossimo). Si se hace Verbos-movimiento ANTES de Essere, hay que cuidar referencias internas; con el orden D-159 (V-mov antes que Essere), V-mov no puede cross-refear a Essere — Essere sí puede cross-refear a V-mov.
- **Profesiones es la más grande** (51). Familia -tore/-trice ya cubierta en Génnum #006/#023/#024/#025 + familia -e/-essa en Génnum #007/#026/#027/#028. Plan 7.2-05 puede cross-refear estas familias para evitar repetir reglas.
- **Sustantivos-irregulares contiene patrones excepcionales** (uovo/uova, dito/dita, braccio/braccia, etc.). Estas son las explanations potencialmente más complejas — cada irregularidad necesita su propia regla explicada.
- **El smoke paramétrico rechaza markdown** (D-126 / D-153). Si una explanation tiene asteriscos por error (e.g., **bold**), el batch falla pre-commit — defensa-en-profundidad para no perder errores en review humana.
- **El campo `notes` autor-internal puede contener cross-refs técnicos** (e.g., "Familia productiva: scrittore→scrittrice"). En `explanation` solo cross-refs pedagógicamente útiles (D-166).
- **Tras Phase 7.2 cerrada, el milestone v1.0 está listo para ship**. `/gsd-complete-milestone v1.0` o equivalente.

</specifics>
