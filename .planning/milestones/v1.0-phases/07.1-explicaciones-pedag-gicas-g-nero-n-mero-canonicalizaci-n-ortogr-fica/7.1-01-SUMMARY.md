## Decisions Made

- **Aplicar los 3 fixes bonus en el mismo commit del re-accent** (no en un commit separado de hygiene): son cambios mínimos (1-2 caracteres cada uno) sobre líneas que ya estaba siendo modificadas por la re-acentuación. Separarlos en otro commit aumentaría el ceremonial sin valor agregado.
- **String-insertion targeted via regex `"explanation": "..."` para preservar formato compacto**: aprendido de Plan 07-02 Batch A — `json.dump(indent=2)` expandiría los arrays inline a multi-línea generando ruido cosmético en el diff. La regex localiza el value del campo explanation y lo reemplaza in-place.
- **Solo 1 entry en el array smoke (no anticipar génnum)**: si Task 2 añadiera ya `{file: 'genero-numero.json', expected: 40}`, el smoke test fallaría porque génnum aún no tiene explanations. Plan 7.1-02 Task 1 añade la entry atómicamente con el ingest del draft, manteniendo tests verdes en cada commit.
