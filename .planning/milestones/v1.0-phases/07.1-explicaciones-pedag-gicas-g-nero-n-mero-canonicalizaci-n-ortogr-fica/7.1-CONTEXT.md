- **Smoke test parametrizado** — reemplaza el bloque hardcoded "Preposiciones explanation coverage" por un loop sobre un array `[{file, expected_coverage}]`. Permite añadir futuras categorías (avere, essere, verbos-movimiento, profesiones, sustantivos-irregulares) en Phase 7.2+ con 1 línea de cambio.

El draft ya pasó review tonal por el autor; se ingresa en 1 commit honesto con su naturaleza pre-revisada (NO se reabre como Batches D-85 Claude-propone — sería negar el trabajo previo del autor).
- **Audit trail PROJECT.md / REQUIREMENTS.md / ROADMAP.md** — registra el canon ortográfico nuevo (D-138) + la 2ª categoría cubierta + el patrón parametrizado para futuras categorías.

## Implementation Decisions

### Canon ortográfico

- **D-135:** **Canon nuevo: español correctamente escrito con acentos y ñ.** Reemplaza el canon Phase 7 ("español sin acentos") que surgió incidentalmente del executor inicial. Justificación del autor: "si está escrito en español que esté bien escrito". Aplica:
  - A las 50 explanations existentes de `content/exercises/preposiciones.json` (re-acentuación retroactiva).
  - A las 40 explanations nuevas de `content/exercises/genero-numero.json` (draft ya las trae correctamente acentuadas).
  - A toda explanation futura (Phase 7.2..7.6).

- **D-136:** **Apóstrofes ASCII U+0027 mantained.** El canon ortográfico NO cambia los apóstrofes — siguen siendo ASCII (no smart quotes `'` `'`). CONT-06 / D-129 sigue vigente. El smoke test paramétrico sigue rechazando smart quotes.

- **D-137:** **Italianismos preservan acentos italianos.** Palabras italianas como `città`, `è`, `perché`, `caffè` mantienen sus acentos originales en italiano (à, è, í, ò, ù). NO se "espanholizan" (e.g., `città` NO se vuelve `citta` ni `cidad`). El canon español aplica solo al texto que es español; las citas italianas mantienen su ortografía italiana.

- **D-138:** **Cross-refs técnicos NO en explanations (canon Phase 7 mantained).** Las explanations NO contienen "ver mc-006", "ref ID-X" ni jerga técnica interna. Las explanations son user-facing en feedback rojo + summary; cualquier referencia debe ser semánticamente útil al alumno (e.g., "Mismo patrón que cuoco→cuochi" sí, pero "(ver mc-006)" no). Notes (campo author-internal) pueden contener trazabilidad técnica libremente.

### Estrategia de re-acentuación

- **D-139:** **1 pasada Claude regenera 50, autor revisa diff.** Aprobado en discuss. Implementación:
  - Claude lee las 50 explanations Preposiciones actuales una a una.
  - Para cada una, genera la versión re-acentuada (el contenido NO cambia, solo se añaden tildes y ñ donde corresponde).
  - Output: un parche/diff de las 50 explanations en una sola pasada.
  - Autor revisa el diff (esperado: ~50-100 líneas modificadas, fácil de escanear).
  - Una vez aprobado, se aplica con un mecanismo que preserva el formato compacto del JSON (string-insertion targeted, no `json.dump`, igual que Plan 07-02 Batches).
  - Commit único: `feat(7.1-01): re-acentuación canónica 50 explanations Preposiciones (EXPL-06)`.

- **D-140:** **Pattern de re-acentuación: añadir tildes faltantes.** Cambios típicos esperados:
  - `preposicion` → `preposición`
  - `articulo` → `artículo`
  - `espanol` → `español`
  - `fisico` → `físico`
  - `practica` → `práctica` (si aparece)
  - `dia` → `día`
  - `mas` → `más` (cuando es adverbio, no la conjunción)
  - `estan` → `están`
  - `esta` → `está` (cuando es verbo, no demostrativo)
  - `tambien` → `también`
  - `Pitfall` queda como está (jerga ya removida en review previo)
  - Italianismos (`città`, `caffè`, `è`, `dalla`, `perché`, etc.) NO se tocan.

### Estrategia de ingesta Género-Número

- **D-141:** **1 commit grande, draft pre-revisado por autor.** Aprobado en discuss. El draft del autor:
  - Ya cumple las acceptance criteria (40/40 ejercicios con explanation válida).
  - 0 smart quotes verificadas en muestra de 10 ejercicios (el resto se valida con el smoke test).
  - Tono D-127 generalmente seguido.
  - 0 markdown markers en explanations.
  - Cross-refs solo en notes (campo author-only) — OK.
  - Apóstrofes ASCII U+0027.
  - **NO se re-propone vía Batches D-85 Claude-propone**: hacerlo sería negar el trabajo del autor. El draft ya es el resultado de la revisión.
  - Commit único: `feat(7.1-02): ingest 40 explanations Género-Número del draft del autor (EXPL-07)`.

- **D-142:** **Distractoras duras mantained.** El objetivo del autor es "demostrar que te lo sabes todo, no algunas cosas". Las distractoras del draft (e.g., mc-020 maestro con familia -essa/-trice como distractoras) se mantienen, aunque exijan al alumno discriminar contra patrones que NO aplican. Es deliberado.

- **D-143:** **mc-037 (psicologo): modern usage acknowledgment mantained.** El draft acepta el uso moderno italiano (`psicologi` sin H aceptado en italiano contemporáneo) además de la regla A1 estricta (`psicologhi` con H). El autor prefiere "realidad sobre teoría" — la explanation educa sobre la regla A1 Y reconoce la excepción moderna.
