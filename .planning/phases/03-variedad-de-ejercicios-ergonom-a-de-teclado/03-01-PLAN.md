<objective>
Slice vertical 1/3 de Phase 3 — `word-buttons` end-to-end con ergonomía de teclado mínima (1-4 multi-choice + 1-9 word-buttons + Enter/Space/Backspace).

Tras este plan, el autor puede lanzar Repaso 20 sobre Avere, encontrar un ejercicio word-buttons mezclado con los multiple-choice existentes, resolverlo con click o teclado y observar la cascada inmediata D-54 al fallar. Toda la mecánica de Phase 2 (`applyImmediateFailure`, `applySessionResult`, contadores monotónicos, racha, summary) sigue funcionando intacta porque word-buttons reusa exactamente el mismo flujo de `sessionResults` que multiple-choice.

Este plan instala tres piezas reusables que 03-02 consumirá sin modificar:
- `applyResultToSession(ex, correct)` — el único call-site de `applyImmediateFailure` para "una sola decisión final" (multi-choice + word-buttons + match-cuando-completa-todas-las-parejas). 03-02 invoca este helper sin cambios.
- `initSubStateForExercise(ex)` — limpia sub-estados de TODOS los tipos y barajea el banco / las columnas según el tipo del ejercicio. Se invoca desde `startSession` y `sessionAdvance` (y `resumeInFlightTest`). 03-02 añade SOLO la rama `match` al switch interno.
- `handleSessionKey(event)` registrado vía `@keydown.window` Alpine — handler global con switch sobre `event.key`. Cubre 1-4 (multi-choice), 1-9 (word-buttons), Enter/Space/Backspace, y deja stubs para las ramas `match` (números sobre matchLeft + letras a-i) que 03-02 rellena.

Purpose: cerrar EXTYPE-02 parcial (cierra tras UAT 03-03) + SESSION-06 parcial (literal: 1-4/Enter/Space/Backspace/1-9; rama match en 03-02). Establecer los tres helpers reusables antes de añadir `match` (03-02) para garantizar **una sola fuente de la verdad** del flujo "fallo → cascada inmediata → persist" — Pitfall #2 evitado a nivel arquitectónico, no a nivel de revisión manual.

Output: app funcional con 2 de 3 tipos + teclado básico; cascada D-54 verificable en localStorage tras un fallo word-buttons; tests verdes para `wordButtons.grade` + validator extendido.
</objective>
