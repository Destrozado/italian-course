## El hallazgo que motiva la forma de este plan (verificado, no supuesto)

El slot `partitivos-clasificacion` (5 variantes, `partitivos.json`) **no es un hueco italiano**. Sus
`prompt` tienen esta anatomía:

- una frase italiana completa y cerrada,
- seguida de una flecha y una pregunta metalingüística **en español**,
- y el hueco se rellena con una etiqueta gramatical **española** (`partitivo` / `preposición` /
  `artículo determinativo`).

Consecuencia mecánica: `scripts/validate-translation-pass.mjs` compone `italianoResuelto` con
`fillGap(prompt, options, correctIndex)`, así que al evaluador le llega una cadena **mixta
italiano+español que no es una frase italiana**. El criterio S5 del doc de validación pide
literalmente que `italianoResuelto` «produce una frase italiana gramatical y natural», y el carve-out
que ya existe cubre el **gloss entre paréntesis**, no esta cola metalingüística.

**Predicción declarada, no conclusión:** es probable que el quórum marque `[S5-italiano]` y/o
`[S2-fidelidad]` sobre estas 5. **No se pre-escribe la excepción**: se corre el quórum, se mira la
evidencia y solo entonces se escribe. Esto es deliberado — el doc se amenda con veredictos literales
delante, igual que E1 y E2 en la Phase 46, no con una corazonada.
