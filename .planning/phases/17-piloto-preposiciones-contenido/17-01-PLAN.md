| backup .json importado → live state | El autor importa un backup; el JSON parseado es input no totalmente confiable que cruza a la migración y al live state |
| localStorage del navegador → migrate() al boot | El blob persistido (posiblemente editado a mano por el autor en DevTools) entra a la cadena de migración |
