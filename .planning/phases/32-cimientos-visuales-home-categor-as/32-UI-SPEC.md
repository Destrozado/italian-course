# Phase 32 — UI Design Contract

> Visual and interaction contract for the **Editoriale foundation layer + Home/Categorías** screen.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **Source of truth:** `design_handoff_italiano_redesign/README.md` (high-fidelity, exact tokens) + variant **1a "Editoriale"** in `Italiano-Home.dc.html`. Recreated in the REAL stack (vanilla + Alpine 3.15.12 + Pico 2.1.1, **no build, NO React**).
> Scope: foundation tokens, self-hosted fonts, `app.css`-over-Pico, tricolore motif, dark-mode disable, and the Home/Categorías screen (mobile column + desktop editorial table). Exercise/Songs/Results/Picker screens are **Phases 33-34** and only inherit the global layer here.

## Spacing Scale

The handoff uses an editorial rhythm; values that fall off the 4px grid are **declared exceptions taken verbatim from the high-fidelity handoff** (do not round them — fidelity is binding per the README "Mantén las medidas exactas").

| Token | Value | Usage |
|-------|-------|-------|
| `space-1` | 4px | Tricolore segment radius gap, micro-gaps (subtitle `margin-top:1px`→use 1px exception, see below), CTA arrow nudge |
| `space-2` | 8px | Ghost-row gap (8px), streak-bar↔label gap (8px), section-overline `margin-bottom` |
| `space-3` | 12px | (12px) tile radius rhythm; not a layout gap |
| `space-row-gap` | 13px | **Exception** — category-row inner gap (dot ↔ text ↔ Examen pill): `gap:13px` (handoff exact) |
| `space-row-pad` | 15px | **Exception** — category-row vertical padding: `padding:15px 0` (handoff exact) |
| `space-4` | 16px | Header block `margin-bottom:16px` (tricolore→header), CTA inner `padding:16px 18px`, base element gap, list `gap:16px` between mock turns |
| `space-header` | 18px | **Exception** — header block `margin-bottom:18px` before the CTA (handoff exact); card radius 18 |
| `space-screen` | 22px | **Exception (KEY)** — horizontal screen padding (handoff: "Padding horizontal de pantalla 22px") for Home, exercises, results |
| `space-6` | 24px | Section-row top margin (`margin:24px 0 4px` for CATEGORÍAS + Contrarreloj row) |
| `space-8` | 32px | Major layout breaks |

**Exceptions (declared, verbatim from handoff — DO NOT round to 4px multiples):**
- Horizontal screen padding **22px** (load-bearing; the whole Editoriale gutter).
- Category row: `gap:13px`, `padding:15px 0`.
- Ghost row gap **9px** top margin from CTA (`margin-top:9px`) + **8px** between buttons; ghost button padding `11px 4px`.
- Header `margin-bottom:18px`; CTA `padding:16px 18px`; CTA→ghost `margin-top:9px`.
- Examen pill padding `7px 15px`.
- Section row `margin:24px 0 4px`; Contrarreloj label↔switch `gap:9px`.
- Streak block `margin-top:7px`; streak bar↔label `gap:8px`; subtitle `margin-top:1px`.
- Touch targets on desktop are mouse-driven; **mobile is the design focus** — keep tap targets comfortable (the existing Phase-28 `@media (max-width:640px)` 44px min-height rules for `.button-row`, `figure table td button` remain valid and must not regress).

## Typography

Three families, exact roles from the handoff scale. **All weights listed are the only ones to be self-hosted** (subset accordingly).

**Families & self-hosted weights (FND-02):**
- **Spectral** (serif) — 400, 500, 600, 700 + italics 400, 500. Titles, category names, exercise prompts, song titles, big score numbers.
- **Hanken Grotesk** (sans) — 400, 500, 600, 700, 800. Overlines, meta, buttons, labels, feedback.
- **Space Grotesk** (mono/numeric) — 500, 700. Progress counters (07/20), stats, score %, ID badges.

| Role | Family | Size | Weight | Line Height | Notes |
|------|--------|------|--------|-------------|-------|
| Display — Home title "Categorías" | Spectral | **38px** | 600 | 1.02 | letter-spacing **−0.6px** (HOME-01) |
| Heading — screen title (Canciones/Resultados, P33-34) | Spectral | 24–30px | 600 | 1.15–1.25 | inherits in later phases |
| Prompt — exercise sentence (P33) | Spectral | 30px | 500 | 1.3 | not this phase |
| Category name (row) | Spectral | **18px** | 600 | 1.15 | HOME-04 |
| Option/pill text (P33) | Spectral | 17–18px | 500 | — | not this phase |
| Italic subtitle ("tema"/topic) | Spectral *italic* | **12.5px** | 400 | — | color `faint` #a39a88, `margin-top:1px` (D-02 derived) |
| Overline (sections) | Hanken | **11px** | 700 | — | letter-spacing 2–2.5px, color `faint-2` #a89f8c, **UPPERCASE** (e.g. `ITALIANO · A1 / A2`, `CATEGORÍAS`) |
| Meta / streak line / feedback body | Hanken | 11–13px | 400 | 1.5 | streak label 11px color `faint` #a39a88; body 12.5–13px color `muted` #8c8576 |
| Primary button (CTA "Repaso 20" title) | Hanken | **16px** | 700 | — | subtitle 12px / 400, opacity .85 |
| Ghost button / "Examen" pill | Hanken | **12.5px** | 600 (ghost) / 700 (Examen) | — | Examen text color `ink` #2b2722 |
| Contrarreloj label | Hanken | 12.5px | 600 | — | color `muted` #8c8576 |
| Counter / score / stats (P33-34) | Space Grotesk | 13–22px | 700 | — | not this phase except IDs |

Body line-height: **1.5** (meta/feedback). Heading line-height: **1.02–1.15** (display/names).

## Color

Single warm-paper palette, **always light** (D-03, dark mode disabled). The 60/30/10 split maps to: paper background (dominant), elevated/surface paper (secondary), green accent (10%, reserved).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f4f0e8` (`paper`) | App/screen background |
| Secondary (30%) | `#fbf8f1` (`paper-elevated`) / `#fbfaf6` (`surface`) | Elevated cards (error/score boxes — P33-34); option/ghost surfaces; tricolore center segment |
| Accent (10%) | `#2f7d56` (`green`) | Reserved list below |
| Destructive / error | `#b5412e` (`red`) | Reserved list below |

**Ink & neutrals (text/hairlines):**
- `ink` `#2b2722` — primary text, titles, category names, Examen pill border+text.
- `muted` `#8c8576` — secondary text/labels, Contrarreloj label.
- `faint` `#a39a88` — italic subtitles, streak label, meta.
- `faint-2` `#a89f8c` — overlines.
- `hairline` `rgba(43,39,34,0.09)` — category-row separators (`border-bottom:1px`).
- `border-soft` `rgba(43,39,34,0.16)` — ghost button borders.
- `streak-track` `rgba(43,39,34,0.08)` — empty streak-bar track.

**Status dot palette (D-01 LOCKED — maps the 3 mock states to the 3 REAL `status` values):**
- `dominada` → **green** `#2f7d56` (mastered; streak ≥21, bar full green).
- `hecha` → **amber** `#b9852f` (in progress; streak 0–20, bar partial amber).
- `no-hecha` → **neutral** `#c4bcab` (`neutral-dot`, "Sin empezar").
- Streak bar fill color follows the same green/amber-by-state rule; `vecesFallada` stays a secondary indicator in the Racha column (does NOT change dot color).

> NOTE: the current `styles.css` `.badge-*` classes invert green/amber (`.badge-hecha`=green, `.badge-dominada`=amber). The Editoriale contract is D-01: **dominada=green, hecha=amber**. The new layer MUST honor D-01 regardless of legacy class colors.

**Accent (green `#2f7d56`) reserved EXCLUSIVELY for:**
1. Primary CTA "Repaso 20" background (full-width).
2. `dominada` status dot.
3. Streak-bar fill for `dominada` rows.
4. Tricolore left segment (decorative motif).
5. (P33-34, inherited) success states, score ring, progress bars — out of this phase.

**Amber `#b9852f` reserved for:** `hecha` status dot + `hecha` streak-bar fill only.

**Red `#b5412e` reserved for:** error/destructive states + tricolore right segment. (In Phase 32 red appears ONLY as the tricolore right segment — there are no destructive actions on Home; Backup destructive flows are unstyled by this phase.)

**Category tint pairs** (bg / text, for song/category tiles — used in P33-34, declared here for the global layer): green `#e8f1ea`/`#2f7d56`, red `#f6e9e6`/`#b5412e`, blue `#e9eef7`/`#3a5a8a`, amber `#f5ecdb`/`#9a6b1f`, purple `#efeaf4`/`#6a4a86`, teal `#e4f0ef`/`#2f6f6b`.

## Components (Phase 32 scope)

### Tricolore motif (FND-04 — reusable)
3 equal segments, `height:4px`, `border-radius:999px`, `overflow:hidden`, `width:~56px`. Colors left→right: green `#2f7d56` / cream `#fbfaf6` / red `#b5412e`. Decorative (top of Home, `margin-bottom:16px`). Must be a reusable element/class available to later phases.

### Home header (HOME-01)
- Optional tricolore bar (top).
- Overline `ITALIANO · A1 / A2` — Hanken 11/700, letter-spacing 2.5px, color `faint-2`, UPPERCASE.
- Title `Categorías` — Spectral 38/600, letter-spacing −0.6px, color `ink`, `margin-top:6px`.
- Header block `margin-bottom:18px`.

### Primary CTA "Repaso 20" (HOME-02)
- Full-width `<button>`, `padding:16px 18px`, `radius-cta` 16px, background green `#2f7d56`, text `surface` #fbfaf6, `shadow-cta`, `text-align:left`, flex space-between.
- Left: title "Repaso 20" (Hanken 16/700) + subtitle (Hanken 12/400, opacity .85). Right: arrow `→` (21px).
- **Behavior (D-05 LOCKED):** keeps current `@click="openPicker('repaso')"` — opens the picker, NOT a direct launch. Subtitle "20 ejercicios al azar · 5 min" is decorative; if it clashes with the picker step, a neutral subtitle (e.g. "Repaso rápido") is acceptable — **the planner decides the copy, the behavior MUST NOT change.**

### Ghost button row (HOME-03)
- Flex row, `gap:8px`, `margin-top:9px` below CTA. Three buttons, each `flex:1`, `padding:11px 4px`, border `1px solid border-soft`, background transparent, `radius-ghost` 12px, text Hanken 12.5/600 color `#5f594d` (muted-ish).
- Order & behavior (D-04 LOCKED): **Test completo** (`@click="openPicker('test-completo')"`) · **Canciones** (`@click="currentScreen='canciones'"`) · **Backup** (`@click="currentScreen='backup'"`). Canciones DROPS from prominent to ghost (supersedes the old Phase-13 D-01 where Canciones was a protagonist).

### Section row + Contrarreloj switch (HOME-05)
- Flex space-between, `margin:24px 0 4px`. Left: overline `CATEGORÍAS` (Hanken 11/700, letter-spacing 2px, `faint-2`). Right: label "Contrarreloj" (Hanken 12.5/600, `muted`) + `gap:9px` + switch.
- Switch: Editoriale toggle; track turns green when on, knob slides (~200ms transition). **Binding unchanged:** reuse `<input type="checkbox" role="switch" x-model="homeExamTimed">` (D-05/HOME-05 — same behavior). Style the Pico switch (or a custom track/knob) to the Editoriale green; do not change the Alpine model.

### Category row (HOME-04 — KEY component)
Per `categoriesForDisplay` row, `display:flex; align-items:center; gap:13px; padding:15px 0; border-bottom:1px solid hairline`:
1. **Status dot** — `9px` round, `flex-shrink:0`, color by D-01 (`dominada`→green / `hecha`→amber / `no-hecha`→neutral).
2. **Center column** (`flex:1; min-width:0`):
   - **Name** — Spectral 18/600, `ink`, line-height 1.15. **Derived (D-02):** split the parenthetical of the existing `name` → title = text before `(`, e.g. "Avere (presente indicativo)" → **Avere**. NO data change, NO `topic` field.
   - **Topic subtitle** — Spectral *italic* 12.5, `faint`, `margin-top:1px`. **Derived (D-02):** text inside the parenthesis, e.g. *presente indicativo*. Categories whose `name` has NO parenthesis show the name only, **no subtitle row**. (Of the 10 categories: 5 have parentheses — avere, essere, articoli, presente-regolare → derive; preposiciones/verbos-movimiento/sustantivos-irregulares/genero-numero/profesiones/partitivos have none → name only.)
   - **Streak block** (`margin-top:7px`, flex `gap:8px`): bar `height:4px; radius:999px; background:streak-track; max-width:110px; flex:1`, fill width = `streakDays/21*100%` in green (dominada) or amber (hecha); label Hanken 11, `faint`, nowrap — `"N/21 d · M ejercicios"` (or `"Sin empezar · M ejercicios"` when streak 0 / no-hecha). **Reuse existing `streakLabel`/`statusLabel` text where possible**; the planner adds a presentational raw-streak getter (see Data Contract).
3. **Examen pill** (`flex-shrink:0`): `padding:7px 15px`, border `1px solid ink`, background transparent, `radius-pill` 999px, Hanken 12.5/700, color `ink`. Reuse `:disabled="!cat.examenEnabled"`, `:title="cat.examenTooltip"`, `@click="startExamen(cat.id)"`.

### Desktop editorial table (HOME-06)
Wider editorial grid/table, columns **Estado · Categoría · Racha · Ejercicios · Examen** (5 columns; "Última vez" is dropped per the design — matches the existing Phase-28 mobile-card behavior). Keep warm paper, Spectral serif, hairline row separators. Technique (restyle existing `<table>` vs grid) is **Claude's Discretion** (planner choice) provided: Pico stays as base, engine untouched, all current functionality preserved (launch category practice, 1-click Examen). The current `<table>` already carries the columns; the planner may drop the "Última vez" `<td>` from the desktop view or hide it — presentation only.
