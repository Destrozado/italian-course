# Phase 34 — UI Design Contract

> Visual and interaction contract for the 4 closing screens of the v1.8 "Editoriale" restyle: **Canciones list**, **song playback (`cancion`)**, **session Results (`summary`)**, **Repaso/Examen picker**. Presentation only — engine untouched. Builds ON the Editoriale layer established in Phases 32-33 (tokens `--ed-*`, self-hosted fonts, top bar, word-buttons, feedback box, status dots, hairline rows). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **Brownfield fidelity note (read before checking Typography/Spacing):** This is a HIGH-FIDELITY brownfield repaint, not a greenfield design. The full type scale, font weights, and spacing tokens are **inherited from the Phase 32 `--ed-*` design system and are verbatim from `design_handoff_italiano_redesign/README.md`** (the declared visual source of truth in CONTEXT.md `<canonical_refs>`). Per locked decisions **CONTEXT.md D-15** (typography) and **D-16** (spacing), the generic greenfield constraints "≤4 type sizes / ≤2 weights" and "all spacing ÷4" **DO NOT APPLY** to these inherited/handoff values — reducing them would be a deviation from the locked source of truth. See the per-section LOCKED notes below.

## Typography

Three established families inherited from the Phase 32 `--ed-*` type system. Roles below are **verbatim from `design_handoff_italiano_redesign/README.md` §Tipografía** (ranges resolved to a single value where the handoff gave a range).

> **🔒 LOCKED — type scale & weights are the inherited design system (CONTEXT.md D-15).** This is a high-fidelity brownfield repaint. The ~12 size roles and weights 400–800 below are **verbatim from the design handoff §Tipografía** and **inherited from the Phase 32 three-family `--ed-*` scale** (Spectral / Hanken Grotesk / Space Grotesk), already shipped in Phases 32-33. The generic greenfield constraint **"≤4 type sizes / ≤2 weights" DOES NOT APPLY** — collapsing this scale would be a deviation from the declared visual source of truth (CONTEXT.md `<canonical_refs>`), not an improvement. These are the real tokens of the locked design system, not invented values. Keep every size/weight exactly as written.

| Role | Family | Size | Weight | Line Height |

| Screen title (Canciones / Resultados) | Spectral serif | 30px (Canciones), 24px (Resultados title) | 600 | 1.1 |

| Song title (list row + featured) | Spectral serif | 17px (list), 19px (featured) | 600 | 1.15 |
| Score number "X/Y" (`summary` hero) | Spectral serif | 30px | 600 | 1.0 |
| Category name (picker row) / affected-category name (summary) | Spectral serif | 18px (picker), 15px (summary cascade) | 600 | 1.15 |
| Italic meta (artist, topic, "Sesión terminada", error explanation) | Spectral italic | 12.5px | 400/500 | 1.5 |
| Overline (section / context) | Hanken sans | 11px | 700 | 1.0 (UPPERCASE, letter-spacing 2–2.5px) |
| Meta / body / feedback / counter labels | Hanken sans | 12.5–13px | 400–600 | 1.5 |

| Accent (10%) | `#2f7d56` `--ed-green` | See reserved-for list below |
| Destructive / error | `#b5412e` `--ed-red` | See reserved-for list below |

**Green accent (`--ed-green`) reserved EXCLUSIVELY for:**
- Picker "Empezar" primary CTA (`.session-cta`) and its green shadow `--ed-shadow-cta`.
- Green check `✓` on selected picker rows (D-13).
- Song progress bar fill on the featured card (state-based, D-02) and `cancion` top-bar progress fill.
- Overline `CONTINUAR` / `EMPEZAR` on the featured card (D-03).
- Score ring filled arc (`conic-gradient(var(--ed-green) Ndeg, #e6ddcd 0)`, D-09/D-10/SRP-03).
- Status dot for song `pasada` (D-07, via `badge-*` → `currentColor`).
- Correct word-buttons fill + correct-answer text in `summary` errors (green underlined resolved gap) — inherited tint tokens `--ed-green-tint` / `--ed-green-on-tint`.

**Red (`--ed-red` / `--ed-red-text` / `--ed-red-tint`) reserved EXCLUSIVELY for:**
- Status dot for song `fallada` (D-07).
- `FALLÓ` label in the "categorías afectadas" cascade (`--ed-red-text` on `--ed-red-tint` pill, SRP-03).
- "Tu: ~~x~~" struck-through wrong answer in `summary` error cards (`--ed-red-text`).
- Wrong word-button tint (inherited `--ed-red-tint` / `--ed-red-tint-border`).

**Neutral / muted (not accent):**
- Song `no-hecha` status dot → `#c4bcab` `--ed-neutral-dot` (D-07).
- Score ring track → `#e6ddcd` (handoff §5 literal; the unfilled arc — distinct from `--ed-streak-track`).
- Cover-tile stripes → `repeating-linear-gradient` using a per-tile tint pair (handoff "tintes por categoría/tema") with `--ed-green-dark` `#296c4a` as the default stripe (Claude's discretion on stripe technique per D-46). Serif initial in the tint's text color.

> Amber `--ed-amber` is the category "en progreso" dot and is NOT used for songs (song triad is `no-hecha`/`pasada`/`fallada` only — D-07). Dark mode is forced OFF (D-32-03); do not add `prefers-color-scheme` rules.

## Copywriting Contract

All strings hardcoded in markup (invariant T-02-01: `x-text` for data only, never `x-html`; button/label text is literal). Interface language: **Spanish**.

| Element | Copy |
|---------|------|
| Primary CTA (Canciones list) | Per row: "Continuar →" if the row is the featured/pending song, "Jugar →" otherwise (arrow matches the "Continuar →" pattern; reuse existing `@click` to `startSong`) |
| Featured card overline (Canciones) | `CONTINUAR` if featured song is `fallada`; `EMPEZAR` if `no-hecha` (D-03, hardcoded per branch) |
| Section overline (Canciones, featured present) | `TODAS LAS CANCIONES` |
| Section overline (Canciones, all `pasada`) | `TODAS LAS CANCIONES` (featured card hidden — D-04) |
| Song row meta | `{artista} · {N} huecos` — artist from splitting `title` on "—" (D-05); N = `phraseCount` (D-06). No "Nivel" (omitted, no source field). If no "—", show title only. |
| `cancion` top-bar progress | "Frase {X} / {N}" (Spanish; rendered via existing counter binding) |
| Primary CTA (Picker) | Reuse `pickerStartLabel` (existing getter — e.g. "Empezar (N ejercicios)") on `.session-cta` |
| Picker selection counter | "{N} categorías seleccionadas" / "1 categoría seleccionada" — driven by `pickerCheckedCategoryIds.length` (D-12) |
| Picker bulk actions | "Seleccionar todo" / "Quitar todo" (reuse `pickerSelectAll`/`pickerClearAll`) |
| Picker Contrarreloj toggle | "Contrarreloj ⏱" label (reuse existing `pickerTimed` binding) |
| Results hero (summary) | Overline + serif title = reuse `summaryHeaderLabel` repainted (D-11). Beside ring: "{X}/{Y}" (Y = `sessionResults.length`, the "/Y" part in `--ed-placeholder` per handoff) + "correctos" + italic "Sesión terminada". |
| Results section: cascade | `CATEGORÍAS AFECTADAS` overline (+ count); per-row optional `FALLÓ` pill (maps to `entry.failed` in `summaryDelta`); right column "{N} ej." |
| Results section: errors | `ERRORES COMETIDOS · {N}` overline; per error: resolved phrase + "Tu: ~~{x}~~ / Correcta: {y}" + italic explanation (reuse `summaryVariantSurface`) |
| Empty state heading (Canciones — all `pasada`) | No dedicated heading. The featured card is **hidden** (D-04); the list under `TODAS LAS CANCIONES` is the whole screen. Absence is the signal (pattern D-108). |
| Empty state body | Not applicable — there is always at least the song list; no "no data" state exists for these screens. |
| Error state | Not applicable — these are presentation screens over engine state that always resolves; double-defense `x-if` guards (`songCurrentPhrase`, `summaryDelta`) prevent partial renders rather than showing error copy. |
| Destructive actions | **None this phase.** No delete/reset/destructive affordance on Canciones, `cancion`, `summary`, or picker. No confirmation UI required. |

## Interaction Contract (phase-specific behaviors)

| Screen | Behavior | Source |
|--------|----------|--------|
| Canciones | Featured card backs the **first pending song** (first `no-hecha` or `fallada` in list order; NOT `lastPlayedAt`). Hidden entirely when all songs `pasada`. | D-01, D-04 |
| Canciones | Progress bar on featured card is **state-based, no numeric fraction** (no "9/14"). | D-02 |
| Canciones | Row tap → `startSong` (existing `@click`). Status dot color from state via `currentColor`. Row CTA arrow ("Continuar →" / "Jugar →") matches the featured-card pattern. | D-07 |
| `cancion` | Word-buttons inherited verbatim from Phase 33 (`bankWithKeys`/`wb-bank`/`wb-answer`/`songCheck`/`songAdvance`). Top bar = back `‹` (`.session-back`, `aria-label="Volver"` inherited) + "Frase X/N" progress; **no timer chip**. **Auto-advance 600ms preserved** (`sessionMode === 'cancion'`). Gap render in lyric + post-check fill at planner's discretion, coherent with D-33-08. | D-08 |
| `summary` | Score ring + "X/Y correctos" on **all** session modes (`repaso`/`test-completo`/`examen`) — single shared screen, no branch by `sessionMode`. Y = `sessionResults.length` (answered count, not launched-set total). | D-09, D-10 |
| `summary` | "categorías afectadas (cascada)" maps to `summaryDelta` (`FALLÓ` ↔ `entry.failed`); "Errores cometidos" reuses `summary-errors`/`summaryVariantSurface`. Repaint only, no new logic. Cascade-list truncation ("+N más") at planner's discretion. | D-11, D-46 |
| Picker | Editoriale hairline rows (Home/category style): serif name + italic subtitle (split `name` on parentheses, D-32-02) + **green tick** when selected, full row clickable (reuse `pickerToggleCategory`). Counter shows **selected categories** count (not exercise count). | D-12, D-13, D-14 |

Transitions: short color/border/position only, ~150–200ms (handoff §Interactions). No complex animation.
